# Alphabétisation

Domaine dédié à la **phase avant Soutien FR** : lettres, sons, syllabes, mots et phrases
à lire (d’après le module lecture soutien-scolaire, adapté en fiches A4).

| Fichier | Rôle |
|---|---|
| `themes.ts` | Thèmes (Alphabet, Voyelles, Consonnes, Syllabes, Mots, Sons complexes, Phrases) |
| `kinds.ts` | Types d’exercice (réutilise les kinds Soutien FR + kinds propres) |
| `series.ts` | Série complète au clic Générer |
| `generate.ts` | Tirage déterministe (délègue aux banques Soutien / données lecture) |
| `data/` | Phrases / grilles adaptées (pas de copie brute) |

Structure UI alignée sur Soutien FR : Thème → Lettre → Son → Type.
