# Audios de compréhension par thème

Même logique que `images/vocabulaire/` : un dossier par thème ClairFLE.

Les fichiers sont préfixés par le niveau d’origine pour éviter les collisions :
`{facile-a1|moyen-a2|difficile-b1}__{nom}.mp3`

Classement d’après les transcriptions de `soutien-scolaire`
(`co-transcripts-scolaire-*.json`, `co-audio*.ts`, `express-*-listening.ts`).
Relancer : `node scripts/remap-audio-themes.mjs`

Voir aussi `scripts/audio-theme-report.json` et `scripts/copy-lib-medias.mjs`.
